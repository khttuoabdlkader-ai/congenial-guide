# congenial-guide
مشروع متخصص في كيفية تشريح مرض السكري

````
ممتاز! اخترت Replit - هذا سيجعل الأمور أسهل بكثير! 🎉

---

🚀 لنبدأ مع Replit خطوة بخطوة

---

📍 الخطوة 1: افتح Replit

1.1 اذهب إلى هذا الرابط:

```
https://replit.com
```

1.2 اضغط على "Sign Up" (تسجيل)

1.3 اختر طريقة التسجيل:

```
□ Sign up with Google (الأسهل)
□ Sign up with GitHub
□ Sign up with Email
```

1.4 أكمل التسجيل (لا يحتاج بطاقة ائتمان!)

---

📌 بعد التسجيل، أخبرني:

```
□ سجلت الدخول بنجاح
□ واجهت مشكلة
```

---

📍 الخطوة 2: أنشئ تطبيقاً جديداً

2.1 في الصفحة الرئيسية، اضغط على "Create Repl"

سترى هذه الصفحة:

```
┌─────────────────────────────────────────────────────┐
│  Create Repl                                       │
│                                                     │
│  [🔵 Create Repl]  ← اضغط هنا                     │
└─────────────────────────────────────────────────────┘
```

2.2 اختر "Import from GitHub"

2.3 الصق هذا الرابط بالضبط:

```
https://github.com/nabilnx/diabetes-starter-app
```

2.4 اضغط "Import"

---

⏳ انتظر قليلاً حتى يتم استيراد التطبيق (10-20 ثانية)

---

📍 الخطوة 3: شغّل التطبيق!

3.1 اضغط على الزر الأخضر "Run" (في الأعلى)

```
┌─────────────────────────────────────────────────────┐
│  [▶️ Run]  [🔵 Share]  [👥 Invite]                │
│                                                     │
│  ← اضغط هنا                                        │
└─────────────────────────────────────────────────────┘
```

3.2 انتظر حتى يظهر التطبيق (سيستغرق 10-20 ثانية)

3.3 ستظهر نافذة التطبيق على اليمين

---

🎉 خلال دقيقة واحدة... سترى تطبيقك!

```
┌─────────────────────────────────────────────────────┐
│  🩺 تطبيق السكري الذكي                             │
│                                                     │
│  أدخل مستوى السكر: [________]                      │
│                                                     │
│  [🔵 احصل على التوصية]                             │
│                                                     │
│  النتيجة: ...                                      │
└─────────────────────────────────────────────────────┘
```

---

📍 الخطوة 4: جرب التطبيق!

4.1 أدخل رقم (مستوى السكر)

جرب هذه الأرقام:

· 65 (منخفض) → ستظهر لك توصية
· 120 (طبيعي) → ستظهر لك توصية
· 200 (مرتفع) → ستظهر لك توصية

4.2 اضغط "احصل على التوصية"

4.3 شاهد النتيجة!

---

📍 الخطوة 5: شارك التطبيق مع الآخرين!

5.1 اضغط على زر "Share"

5.2 انسخ الرابط

5.3 أرسله لأي شخص يريد استخدام التطبيق!

---

🎬 الآن... أخبرني!

```yaml
ما الذي تراه الآن؟

□ التطبيق يعمل! أرى الواجهة
□ أرى أخطاء (صفها)
□ لا يظهر شيء
□ التطبيق يعمل لكن أريد تعديله
```

سأنتظر ردك لأتابع معك! 🚀
````
